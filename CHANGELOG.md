# Changelog

## 0.1.0 — initial source release

- Private, server-rendered technology news homepage with six source-based categories.
- Conditional AIHOT polling, persistent caches and truthful stale/error states.
- Optional Muse questions with complete-answer callbacks and restricted commands.
- Monochrome paginated reading, access-code login and submission replay protection.
- Portable local startup, generic Linux service templates, offline original-content demo, tests and documentation.

Excluded: personal runtime state, tokens, device backups, bundled SDK, cloud schedules and the unverified native fullscreen experiment.
